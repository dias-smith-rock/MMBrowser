Run two Facebook accounts on iPhone without an app clone

Skip clone apps. Use XBrowser Spaces for two independent Facebook web sessions on one iPhone.

Download XBrowser How Spaces work

The pain

Clone apps raise trust and App Store concerns. Facebook’s own switching still isn’t the same as fully separate browser profiles.

How XBrowser solves it

Space per Facebook login. Isolated cookies, history, and tabs—no second APK, no logout dance.

Step-by-step

  1. Create Space “FB-Personal” and Space “FB-Page/Brand”.
  2. Sign into facebook.com (or m.facebook.com) in each Space.
  3. Keep both signed in; switch with the Space chip.
  4. Lock a Space if page access should stay private.
