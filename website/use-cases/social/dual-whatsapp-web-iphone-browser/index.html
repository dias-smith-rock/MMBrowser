Dual WhatsApp Web on one iPhone browser

Run dual WhatsApp Web sessions in a single iPhone browser using XBrowser Spaces and optional Split View.

Download XBrowser How Spaces work

The pain

One browser profile = one WhatsApp Web session. Opening a second usually kicks the first.

How XBrowser solves it

Bind each WhatsApp Web login to its own Space. Split View shows both panes without cookie mixing.

Step-by-step

  1. Create Personal and Work Spaces.
  2. Link WhatsApp Web in Personal.
  3. Link the second account in Work.
  4. Open Split View: top pane Personal, bottom pane Work.
  5. Drag the divider and chat in both without logging out.
