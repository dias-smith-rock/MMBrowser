How to set a sleep timer for web video on iPhone (YouTube / Bilibili)

Set a sleep timer for YouTube, Bilibili, and other web video on iPhone—countdown, fade-out, and background play steps.

Why a web sleep timer?

With Safari, bedtime web video often stops on lock—or runs all night and drains the battery. XBrowser combines background play with a Sleep Timer in one flow.

Steps

  1. Open YouTube, Bilibili, or another web media page in XBrowser.
  2. Start playback, open Sleep Timer, and pick a duration (for example 30 minutes).
  3. Lock the phone. Playback can continue; near the end it fades out and stops.

Tips

  • White-noise and podcast sites work the same way.
  • If a site blocks background media, results may vary—prefer pages that expose a media session.
